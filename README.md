# Vortex Hydro

## Struktur proyek

- `index.html` — halaman utama dan titik masuk situs.
- `ui/` — kode antarmuka, termasuk `styles.css` dan `script.js`.
- `ui/mobile/mobile.css` — penyesuaian khusus layar mobile. File ini dimuat setelah stylesheet utama agar aturan mobile dapat mengubah tata letak tanpa memengaruhi desktop.
- `assets/graphics/software-icons/` — ikon perangkat lunak.
- `assets/graphics/team/` — foto tim, placeholder, dan panduan penamaan foto.

Animasi yang digunakan situs saat ini dibuat langsung dengan CSS dan JavaScript di folder `ui/`, jadi belum ada aset animasi terpisah untuk dikelompokkan.
